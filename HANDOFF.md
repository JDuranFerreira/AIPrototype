- **The next goal (the user, 2026-10-04): the brain should be able to **code** — read a program, work out what every step does, run it, check its own answer, and be taught new procedures the way it is taught stories** (the teacher shows worked examples → the brain reproduces each one with its own process → it keeps the procedure only if that matches; that is exactly how the P3/P5/P6 tools are taught, and `%` and `^` are now taught the same way, see §4).
  - **It is not ready yet, and the honest reason is reading, not arithmetic:** arithmetic is exact and worked out step by step, but on human-written problems it is weak (ASDiv grade 1 test 13.4% right, grade 5 2%) and its own confidence claims there were only ~36–43% true. A program is long, precise text: teaching code now would fill its frames with confidently wrong meanings.
  - **What has to be true first** (order agreed with the user, §6 item 8): numbers it can *teach itself* to a child with worked examples → reading that survives real sentences (target: ASDiv grade 1 above 30%, and claims that are true at least 80% of the time) → a "recipe" domain where instructions in words become steps executed with its own arithmetic and tools, each output checked by the teacher → working memory and plans long enough to hold a whole program (now 7 slots and 2–3 steps).
  - **Not allowed as a shortcut:** calling a Python interpreter from inside the brain, or hand-writing a solver per problem. The brain must work it out and check it itself (that is the whole point, and §5 says so).

## 3. Architecture: regions (`regions.py` → `Mind`)

Regions are partitioned **by function, the way a brain is** — not by subject or by where the data came from (refactor 2026-10-04; before it was `kindergarten` / `english` / `school`; the coordination region was added the same evening). `Mind.regions()` returns these seven, and `Mind.report_card()` returns the report card, which is bookkeeping and deliberately **not** a region. The old attribute names still work as aliases: `mind.kindergarten` → `mind.language.reading`, `mind.english` → `mind.language.english`, `mind.school` → `mind.report`, `mind.strategy` → `mind.coordination.strategy`.

| Region | File(s) | What it does |
|---|---|---|
| **language** | `reading.py` (was `kindergarten.py`), `language.py`, `english.py`, `english_chat.py`, `measure.py`, `reader.py`, `reasoner.py` | words, word meanings, grammar, sentence frames, reading stories and learned phrases. Two sub-stores: `mind.language.reading` is the reading engine (Hebbian word learner, world facts from scenes, verbs, **sentence frames**, pronouns, question meanings, stories acted out in a mental model with unknowns; says *understood* only if it knows every word, and learns from an answer by finding the one misread sentence), and `mind.language.english` is word forms, rules noticed from examples and confirmed by the teacher, exceptions kept in memory, relations (synonym, antonym, is-a with reasoning), tense and agreement. Learned phrases and patterns → **measure** (unit conversions from known facts) → **reader** (template classifier, MAWPS/ASDiv-A + school) → optional helper LLM (**off**); `reasoner.py` (step-by-step perceptron) is written but **not trained or integrated** (too slow; see §6) |
| **knowledge** | `regions.py` (`class Knowledge`) | facts about the world, from **two sources in one region**: `facts` told directly (capital of France → Paris; unit facts such as cents in a dollar, area of a rectangle) and the `scene` semantic network learned from scenes and stories (a puppy is a young dog). The scene store is the *same object* as `mind.language.reading.know` — shared by `Mind._bind()`, never copied |
| **memory** | `regions.py` (`class Memory`) | the stories it lived through (episodes kept per stage), replayed in sleep. `mind.memory.episodes is mind.language.reading.episodes`: the reading engine owns the store and the region is a view over it |
| **arithmetic** | `brain.py`, `parts.py`, `compose.py`, `rules.py`, `equations.py` | 3 learned sections (+, −, ×; small NumPy nets, 11,313 weights); memory; rules with letters (shortcuts, plus explaining rules such as `a*b = a*(b-1)+a`); fixed written methods (column +/−, long ×, long ÷, `div`/`rem`/`divup`, exact fractions); missing numbers by inverse rules; comparing; simplest form (Euclid) |
| **prefrontal** | `planner.py` | plans (`plan: a = 3*4; a-2`) and working memory (7 slots, `last`). Action selection moved to the **coordination** region |
| **coordination** | **`coordination.py`**, `strategy.py` | the **tools**: the worked procedures for whole groups, percent, greatest common factor, least common multiple and the unitary method (moved out of the reading engine, which used to hold them); which tools it was taught (`rules`), where each may be used (cue words: the hand list plus the words each tool was taught with), how well each pays off (`stats`: tried/right/steps — rewarded when a story's tool explanation is confirmed or a worked example checks out), and action selection — guess or work it out, learned from ✓/✗ rewards (`mind.strategy` is an alias) |
| **monitor** | `monitor.py` | confidence; number sense (±20%); checking by undoing (8−6 = 2 for 2+6 = 8, never using the fact being checked); doubts |
| **strategy** *(a component of coordination, not listed separately by `regions()`)* | `strategy.py` | basal ganglia: guess or work it out, learned from ✓/✗ rewards |

**Not regions** — they belong to the regions above:
- **report card** (`school.py`, `curriculum.py`, `curriculum_p3.py`, **`primary.py`** → `brain_state/report/`): bookkeeping of levels, subjects, exams and grades AL1–AL8. `primary.py` is the **world-based** school (P1–P6): readiness pre-test → lessons → sleep → self-assessment → exam on unseen items → descriptive feedback and retake; its lessons are stories with scenes (`SchoolTeller`), its exams are new stories, and the outside exam is ASDiv of that grade (subject `world` on the card).
- **`kindergarten.py`** is now a **compat shim**: it re-exports `Reading` (plus `WordLearner`, `WorldKnowledge`, `ActionLearner`, `words_of`) from `reading.py`, so old imports keep working. The simulated world and storyteller that feed the reading engine are still `world.py`, `stories.py`, `storyreader.py`.

The command interface `serve.py` (JSON on stdin and stdout) is used by AgenticOS. Actions: `ask`, `feedback`, `tell`, `teach`, `learn_phrase`, `auto`, `rule`, `notice`, `rules`, `doubts`, `english_rule`, `solving_rule`, `sleep`, `exam`, `stats`, `forget`, `reset`, `kindergarten {lesson: words|facts|actions|stories|all|exam, rounds}`.

`kindergarten {lesson: P1|P2}` runs one level of the world-based school; in the Brain tab: `school P1` / `school P2`.

The reading engine in the language region answers first (`handle_kindergarten`; the action is still called `kindergarten` for compatibility):
- Stories with a "how many / how much" question are acted out. If it can't act the story out, the rest of the language region (phrases, reader) answers.
- It also answers `what is red?` (a word meaning), `how many legs does a puppy have?` (the **knowledge** region) and `what does a lamb say?`, and learns `a zebra has four legs` into the knowledge region.
- `story = answer` and ✓/✗ teach it.
- In the Brain tab: `teach kindergarten [words|facts|actions|stories] [n]`, `kindergarten exam`, and the **Kindergarten** button — all three drive `mind.language.reading`.

It trains in **129 s for 6 epochs** since `reasoner.py` was vectorised (2026-10-02, parity-checked against the old loop by `benchmarks/bench_reasoner.py parity`). An epochs sweep on SVAMP-1000 (GSM8K first 100 in brackets): 1 → 30.0% (6%), 4 → 28.8% (5%), 6 → 28.7% (5%), 12 → 26.3% (5%) — the default stays at 6 (the pre-set protocol), because first-300 peaks at 4 (21.3%) while SVAMP-1000 and GSM8K favour 1; beyond 6 everything degrades, like the reader's surface-pattern overfitting.

## 7. Working tips (lessons from this project)
- **P3-P4 development:** `benchmarks/try_level.py build|run|look` (save a brain after P2, run one level on a copy in ~1-2 min, ASDiv dev by problem type, `--show TYPE`). Trace exam failures by kind with a small script over `primary.exam_items(level, 'A', 0)` + `reader.solve`.
- **Experiments:** `benchmarks/compare_frames.py pooled|balanced sleep|nosleep [SAY] [oldkinds]` (two rounds, dev + test halves, world exams, kindergarten exam; about 15 min, runs in parallel fine on 20 cores). `benchmarks/try_new_kinds.py [balanced] [oldkinds] [--save FILE]` (one P1 round, exam by kind, the dev problems of the new situations; about 4 min). Load a saved brain with `Mind.load(path)` (the reading engine is `mind.language.reading`; `Reading(data)` builds one from a state dict) and trace failures with `reader.solve`.
- **When adding a story kind**, check the OLD kinds by kind too (`try_new_kinds.py oldkinds` vs not): a new phrasing can teach a shared word ('were', 'collected') a wrong meaning.
- **Bash on Windows mangles backslashes and `…`** in heredocs and `python -c`. For any patch with regexes or escapes, write a `.py` file with the Write tool (to the scratchpad) and run it. Long heredocs can also be cut off silently: check the file landed.
- **Perception rules in `storyreader.py` interact.**
  - The rules: owners (persons, then uncounted things, then the subject), settings (`_WHERE` + determiner), `_NOT_NOUNS`, `_BETWEEN`, pronoun evidence (unnamed referents only, at least 3 frames).
  - After any change, rerun the kindergarten exam, P1, P2 and `run_school.py` together.
  - Debug a story of one kind with `SchoolTeller(seed=99).tale(kind)` plus `reader.solve`.
- **Kindergarten internals:**
  - Meanings are `target=expression` over slots (`P1.T1=P1.T1-N1`, `ANS=P1.T1@D1-P1.T1@D2`, `F:` = at the start).
  - `Frames.table[kind][key] = {n, m: counts, o: opportunities}`.
  - Candidate order: sure = count/(chances+1) times TRUST[rank] (word in its frame > word anywhere > frame shape > anything).
  - Debug a story with `reader.solve(text)`; it returns `(answer, how, trace)`.
- **PowerShell pipes add a BOM.** `serve.py` decodes stdin with utf-8-sig, so it copes.
- **Printing Unicode in a cp1252 console fails.** Use `PYTHONUTF8=1`. `serve.py` writes UTF-8 bytes.
- **Grading and exams:** `school.take_exam` runs on a deepcopy of the brain (read-only). Always check that `brain_state` is unchanged after read-only checks (`diff -rq` against a copy).
- **Timing and profiling:** time a level with `python -m brainlike.primary P1 --dry-run` (read-only, ~32 s since 2026-10-04, was 76 s) or `python -m cProfile -o p.prof -m brainlike.primary P1 --dry-run` + `pstats`. The reading engine has three caches — `storyreader.uses` (module memo), `Frames._sure_cache` and `WordLearner._links` — invalidated ONLY from their writer (`credit()`, `observe()`); if you add another place that writes `Frames.table` / `by_situation` / the word counts, bump the revision there too or the caches go stale. Exams are reproducible run-to-run since the `library.Exams.nearest` tie-break fix (no `PYTHONHASHSEED` needed).
- **Back up `brain_state/`** before anything that teaches the real brain.
- **AgenticOS backend restart:**
  - Stop the processes listening on :8420.
  - Run `Start-Process powershell -ArgumentList '-NoExit','-NoProfile','-File','C:\AgenticOS\scripts\start.ps1'`.
  - Then poll `POST /api/brainlike {"action":"stats"}` until it answers.
